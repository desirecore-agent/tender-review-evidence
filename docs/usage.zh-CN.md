# 使用独立证据复核

提供复核问题、相关招标/投标/补遗材料，以及待独立检查的发现或草稿。明确授权位置和指定交付方式。小范围任务同样有效，不需要完整六类导出。

例如：“检查这三个高风险发现是否成立，查看补遗和其他投标附件中的反证。说明保留、撤回或补查什么，以及依据在哪。”

应收到逐项可用意见、范围和限制。复核员可以发现新遗漏，但新增问题须标明由另一专业成员确认。仅阅读和计划不算完成。证据不可用时，应说明影响哪个结论、需要什么补充，并交付已完成部分。

材料修改时明确变更，要求复查受影响结论，不把旧判断静默用于新文件。

明确需要旧 v1.2 JSON 导出时另行提出，参见[依赖](dependencies.zh-CN.md)。导出校验不证明业务准确性。普通自然语言复核只需本任务适用的文档、图像和计算能力。

仅提供有权处理的材料。配置的模型可能处理发送内容，额外服务需授权。成果辅助人类决策，现有评测为合成样本，不证明真实标书准确率。
