# Recovery

For ordinary review, preserve completed opinions and identify the smallest missing piece.

- Missing or unreadable evidence: explain which judgment is affected, request a precise file/page/clearer image and complete independent checks.
- Interrupted work: resume from the current request and available results, deliver actual opinions rather than repeating a plan.
- Disagreement: keep both interpretations and source locations, request a focused specialist check.
- New source version: recheck affected conclusions; do not silently relabel old work.
- Requested file cannot be written: disclose the failure, provide the usable opinion in the available response and state that requested file delivery remains incomplete.

For an explicitly requested legacy structured export only:

- Missing Python/package: initialize a permitted isolated environment as described in [dependencies](dependencies.md), or report export validation unavailable.
- Missing/corrupt schema: use the installed team's `shared/contracts/schemas/`; do not skip validation and claim success.
- Missing product, conflicting manifest versions or inconsistent coverage: correct the affected export based on actual evidence, preserving the old result and reason for correction.
- Validator failure: report its real result. The export remains unvalidated; independently completed business opinions remain usable with stated limits.

Do not overwrite originals, widen access or manufacture a pass.
