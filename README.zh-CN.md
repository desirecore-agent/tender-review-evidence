# 证据复核员

0.2.0 版本检查重要标书发现是否成立、是否遗漏反证和关键义务，以及建议能否实际整改。

从[使用指南](docs/usage.zh-CN.md)、[复核技能](skills/tender-evidence-review/SKILL.zh-CN.md)和[质量清单](skills/tender-evidence-review/checklist.zh-CN.md)开始。交付保留、撤回、调整或补查意见，并提供理由及可定位依据。未指定形式时，可用的对话意见、表格或报告均可。

保留的 Python 校验器仅供明确要求的旧结构化导出使用。普通业务复核不需要 Python、六件文件包或输入输出 Schema。参见[可选依赖](docs/dependencies.zh-CN.md)。

所选模型可能处理提供的文本图片，未经授权不向额外服务外传。成果辅助审查，不鉴真、不保证中标。已有测试使用合成材料，发布本身不证明真实标书效果或生产可靠性。
