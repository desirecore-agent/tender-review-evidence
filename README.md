# Independent Evidence Reviewer

Version 0.2.0 checks whether important tender-review findings are supported, whether counterevidence or key obligations were missed, and whether recommendations are actionable.

Start with [usage](docs/usage.md), the [review skill](skills/tender-evidence-review/SKILL.md) and its [quality checklist](skills/tender-evidence-review/checklist.md). Deliver retain/withdraw/revise/follow-up opinions with reasons and locatable evidence. A useful chat response, table or report is sufficient unless a specific format was requested.

The retained Python validator is only for explicitly requested legacy structured exports. Ordinary substantive review does not require Python, a six-file pack or input/output schemas. See [optional dependencies](docs/dependencies.md).

The selected model may process supplied text and images. Do not transmit materials to additional services without authorization. This is review assistance; it neither authenticates documents nor guarantees award. Recorded testing used synthetic material; real-tender effectiveness and production reliability are not established by publication alone.
