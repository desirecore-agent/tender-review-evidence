# Natural-language assignment guide

A clear request is sufficient. Explain the project, the findings/draft to review, authorized source materials, important questions, quality criteria and requested delivery. Identify known limits and what should happen if material cannot be read.

Example: “Independently review the high-risk issues in the Lead draft using these tender, bid and amendment files. Search for exceptions and responses elsewhere. Say which issues to retain, withdraw or investigate, with locatable evidence and actionable next steps. Leave originals unchanged. A table in your response is sufficient. Deliver useful partial work and identify any unavailable evidence.”

No TaskSpec, metadata preflight or fixed JSON envelope is required. Actual material still needs to be inspected. Use task-provided paths and platform permissions; a request cannot grant access that the platform has denied.

See [the skill](SKILL.md) for substantive quality standards.
