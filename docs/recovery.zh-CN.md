# 恢复指引

普通复核应保留已经完成的意见，定位最小缺口。

- 证据缺失或不可读：说明影响哪个判断，明确需要的文件、页或清晰图像，继续完成独立检查。
- 工作中断：结合当前任务和已有成果继续，交付实际意见而非重复计划。
- 存在分歧：保留两种解释及依据位置，提出聚焦的专业补查。
- 原件更新：复查受影响结论，不把旧成果换标签当新成果。
- 指定文件写入失败：说明失败，在可用回复中提供意见，同时指出要求的文件交付仍未完成。

仅对明确要求的旧结构化导出：

- Python 或依赖缺失：按[依赖指南](dependencies.zh-CN.md)初始化获准隔离环境，或说明导出校验不可用。
- Schema 缺失或损坏：使用已安装团队的 `shared/contracts/schemas/`，不跳过校验声称通过。
- 导出缺件、材料版本冲突或覆盖不一致：依据实际证据修正受影响导出，保留旧结果及修改原因。
- 校验失败：报告真实结果。导出仍未验证，已独立完成的业务意见可以在明确限制后使用。

不覆盖原件、不扩大权限、不制造通过。
